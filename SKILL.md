# Video Downloader

Use this skill to download user-provided web videos through the bundled script:

```bash
~/.codex/skills/video-downloader/scripts/download-video.sh "VIDEO_URL" "OUTPUT_DIR"
```

## Workflow

1. Confirm the URL is intended for content the user owns or has permission to download when the situation is ambiguous.
2. Run `scripts/download-video.sh` with the page URL and optional output directory.
3. Prefer highest available quality unless the user specifies a resolution.
4. After download, verify the output file exists and inspect basic metadata with `ffprobe` when available.
5. Report the final local path, resolution, duration, file size, and any quality limitation observed.

## Examples

Download to the default folder, `~/Desktop/video-downloads`:

```bash
~/.codex/skills/video-downloader/scripts/download-video.sh "VIDEO_URL"
```

Download to a requested folder:

```bash
~/.codex/skills/video-downloader/scripts/download-video.sh "VIDEO_URL" "$HOME/Desktop"
```

## Notes

- The script rewrites Douyin selected-page URLs such as `https://www.douyin.com/jingxuan?modal_id=7619750213330177321` to `https://www.douyin.com/video/7619750213330177321` before downloading.
- If direct extraction fails because a site requires login, cookies, CAPTCHA, DRM, or paid access, explain the blocker and do not claim the download is complete.
- Do not bypass DRM or access controls.
- Keep filenames generated by `yt-dlp` unless the user requests a specific name.
